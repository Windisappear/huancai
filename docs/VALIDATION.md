# 验证记录

日期：2026-09-09。环境：Windows、Node 24.11.1、本机 Edge，独立 PostgreSQL 15 / Redis 6 测试容器，DEMO_MODE=true，私有本地测试文件目录。未调用真实 AI 或支付 API。

## 已验证

- Next.js standalone 生产构建、TypeScript 检查通过。
- 7 项单元测试：部分结果金额守恒、非法结算参数、72 小时精确边界、提前删除、生产禁用测试模型及未验证适配器。
- 7 项 PostgreSQL 集成测试：并发余额不足、重复结算、任务去重及 Outbox、外部用户报价拒绝、重复到账与退款、驳回退款释放、丢失队列记录的恢复且仅冻结一次。
- 3 项浏览器场景通过：注册／恢复码、测试充值、文生图任务、下载、跨设备余额与历史、旧恢复码失效；参考图上传、图生图、图片尺寸、用户隔离、管理员退款、CSRF、过期访问拒绝及物理清理后保留账本；390px 手机布局无横向溢出。
- 已检查桌面和移动截图。测试文件输出均有非 AI 生成标识。
- 最后一次参数复用修改后，针对图生图、完整参数／参考图复用、清理和管理退款的浏览器回归再次通过；最终健康接口返回 ok:true。
- 在独立数据库恢复财务备份，钱包与流水核对一致；创作内容表没有被恢复。临时归档和测试恢复库已清理。
- 本地和生产 Compose 结构校验通过；Docker 引擎重启后项目测试数据仍存在。
- npm audit 在升级 sharp 及覆盖 deepmerge-ts 版本后为 0 已知漏洞。
- standalone 发布产物移除框架自动复制的 .env 文件，排除 .local 和 test-results；运行时从外部注入环境。

## 验证中发现并修复

- standalone 会改变当前目录，造成测试 Web 与 Worker 使用不同文件路径：统一绝对 LOCAL_STORAGE_ROOT，修复后图生图和下载通过。
- Prisma Windows DLL 被正在运行的服务器锁定：文档要求生成／构建前停止项目进程。
- 模型、价格和图片到期的服务端约束不依赖前端；钱包非负、任务金额范围、实体归属和流水禁止更新另有数据库约束。
