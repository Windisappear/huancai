选择目标模型。 支持 url 和 b64_json 两种返回格式。 可在 JSON 中附带 image 作为参考图，是否生效取决于实际命中的图像渠道。 n 不传或显式传 0 时，统一层会回退为 1 。 请求头 Authorization string 必填 请求身份认证。使用 Bearer Token，示例值： Bearer YOUR_API_KEY 。 Content-Type string 必填 请求内容类型，必须设置为 application/json 。 请求体 model string 必填 固定传 gpt-image-2 。 prompt string 生成提示词。对于文生图语义应视为必填。 n integer 生成数量。若不传或显式传 0 ，统一层回退为 1 。 size string 输出尺寸。官方 gpt-image-2 支持 auto （默认，模型按提示词自选）和任意 宽x高 自定义尺寸：宽、高均须为 16 的倍数，宽高比在 1:3 到 3:1 之间，最长边不超过 3840 ，总像素在 655360 到 8294400 之间（超过 2560x1440 属实验性）。常见基础档位为 1024x1024 、 1536x1152 、 1536x1024 、 1024x1536 、 1920x1080 、 1080x1920 。 image string | array<string> | object 可选参考图输入。常见写法是 Base64 字符串或 Base64 数组，适合需要图像风格参考的渠道。 response_format string 返回格式，常见值为 url 、 b64_json 。 quality string 质量字段。官方取值为 low 、 medium 、 high 、 auto （默认 auto ）。 low 适合快速草稿， high 保真度最高且 token 消耗显著更高。是否真正生效取决于最终命中的渠道。 style string | object 风格字段，原样透传给支持的上游。 background string | object 背景控制字段，原样透传给支持的上游。注意：官方 gpt-image-2 仅支持 opaque 、 auto （默认 auto ），不支持 transparent （与 gpt-image-1 不同）。 output_format string 输出图像格式。官方取值为 png （默认）、 jpeg 、 webp 。 output_compression integer 输出压缩级别，整数 0 – 100 ，仅 output_format 为 jpeg 或 webp 时生效。 moderation string 内容审核强度。官方取值为 auto （默认）、 low （过滤更宽松）。 watermark boolean 显式水印开关。 false 与不传语义不同。 基础比例与尺寸档位 预设 实际目标尺寸 1:1 1024x1024 4:3 1536x1152 3:2 1536x1024 2:3 1024x1536 16:9 1920x1080 9:16 1080x1920
